# 项目启动指南（Windows / PowerShell）

> 适用于：`E:/毕设/基于IGinX的数据与模型智能关联管理系统设计与实现/code`

---

## ✅ 1. 前置环境

- **JDK 17**（当前机器路径：`C:/Program Files/Java/jdk17`）
- **Maven 3.x**
- **Node.js + npm**
- **Docker Desktop**

---

## 🐳 2. 启动依赖容器

### 2.1 启动已存在容器

```powershell
docker start iginx_zk iotdb iotdb_6668 iginx_assoc_pg pg_local_demo2
```

### 2.2 查看容器状态

```powershell
docker ps
```

> 说明（端口）  
> - `iginx_zk`：Zookeeper `2181`  
> - `iotdb`：IoTDB `6667`  
> - `iotdb_6668`：IoTDB `6668`  
> - `iginx_assoc_pg`：PostgreSQL `5432`（后端元数据）  
> - `pg_local_demo2`：PostgreSQL `5433`（结构化演示库）

## 🖥️ 4. 启动后端（Spring Boot）

### 方式 A：前台启动（占用终端）

```powershell
$env:JAVA_HOME="C:/Program Files/Java/jdk17"
$env:PATH="$env:JAVA_HOME/bin;$env:PATH"
mvn -f "E:/毕设/基于IGinX的数据与模型智能关联管理系统设计与实现/code/iginx-assoc-backend/pom.xml" spring-boot:run
```

### 方式 B：后台启动并输出日志（推荐）

```powershell
cmd /c "set JAVA_HOME=C:/Program Files/Java/jdk17& set PATH=%JAVA_HOME%/bin;%PATH%& mvn -f \"E:/毕设/基于IGinX的数据与模型智能关联管理系统设计与实现/code/iginx-assoc-backend/pom.xml\" spring-boot:run > \"E:/毕设/基于IGinX的数据与模型智能关联管理系统设计与实现/code/iginx-assoc-backend/backend.out.log\" 2> \"E:/毕设/基于IGinX的数据与模型智能关联管理系统设计与实现/code/iginx-assoc-backend/backend.err.log\""
```

## 🧯 7. 常用停止命令（可选）

```powershell
# 停止后端（找到 8080 对应 PID）
$pid = (Get-NetTCPConnection -LocalPort 8080).OwningProcess
Stop-Process -Id $pid -Force

# 停止容器
docker stop iginx_zk iotdb iotdb_6668 iginx_assoc_pg pg_local_demo2
```

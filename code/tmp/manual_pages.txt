3.2.3.23 KEY 列 
IGinX 中，KEY 列是相对于其他列较为特殊的一列，可以通过 AS 把 KEY 列降级
为普通列或把普通列升级成 KEY 列。 
3.2.3.23.1 KEY 列降级为普通列 
KEY 列降级为普通列是通过在 SELECT 子句中使用 KEY AS ... 来实现的。例如： 
 
IGinX> SELECT KEY AS a, int, KEY AS b FROM test WHERE key >= 0 AND key <= 10; 
 
3.2.3.23.1 普通列升级成 KEY 列 
普通列升级成KEY 列是通过在SELECT 子句中使用 ... AS KEY 来实现的。例如： 
 
IGinX> SELECT int AS KEY , string FROM test WHERE key >= 0 AND key <= 10; 
 
需要注意的是： 
 每个SELECT 子句里最多只能使用一个 AS KEY； 
 由于 KEY 列的类型是 long，因此当原先的普通列的类型不是 int 或 long 时，会进
行类型转换。 
 boolean：false 为 0，true 为 1 
 float 或 double：四舍五入转为long 
 string：若为数字字符串，解析成 long 
 最后会对类型转换后的结果进行重复检测，有重复值时报错。
